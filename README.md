# near-sdk-zig: Building smart contracts with Zig

This repo demonstrates that there is minimal setup needed to start building a smart contract for NEAR Protocol in Zig.

[Here](https://gist.github.com/vgrichina/10ea303ab1bbf3d4069cd30d28f6340e) is a small contract demo.

For more advanced SDK, check out [DaviRain-Su/near-sdk-zig](https://github.com/DaviRain-Su/near-sdk-zig).
